# How we write here

Keep text plain. Readers may not use English as their first language.

## Rules

- Use short sentences. Maximum 20 words.
- One idea per sentence.
- Use plain words. Write "use", not "utilize".
- Use the same word for the same thing. Write "skill" every time. Write "list" every time.
- Use active voice. Write "Click Edit." Do not write "Edit can be clicked."
- Write steps as numbers. One action per step.
- No jargon.
- No hype or marketing words.
- No emojis.

## Example

Good: "Click Edit. Add one line. Click Commit changes."

Not good: "Simply utilize the Edit button to seamlessly add your entry."
