# How to suggest a skill

Use these steps to add a skill with a pull request. You need a free GitHub account.

Read [STYLE.md](STYLE.md) first. It explains how to write the row.

## Steps

1. Open [README.md](README.md) on GitHub.
2. Click the pencil icon. It says Edit.
3. Pick the group that matches the job. Add one row to the table there. Copy the row above it. Write ⭐ ? in the Stars column. A robot fills in the number.
4. Click "Commit changes".
5. Choose "Create a new branch and start a pull request".
6. Fill in the short form.
7. Click "Create pull request".

## Rules for a skill

- The repository is public.
- It has a SKILL.md file or clear docs.
- You checked that it works.
- The "What it does" cell is one plain sentence.
- Do not copy skill text into this list. Link only.
- No affiliate links.
- No duplicates. Check [README.md](README.md) first.

## What happens next

Harish reads your change. He merges it, or he tells you why not.

## No GitHub skills, or no pull request?

Open an issue instead.

1. Open the Issues tab.
2. Click "New issue".
3. Choose "Suggest a skill".
4. Fill in the form and submit it.
