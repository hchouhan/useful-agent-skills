# Useful Agent Skills

A list of skills made by other people, grouped by job.

A skill is a set of instructions for an AI coding agent. Examples of agents are Claude Code, Codex and Cursor.

We do not copy skills here. Each row links to the original repository.

**How to use the list:** pick the group that matches your job. Pick a skill. Click its link. Follow the instructions there.

Star counts update by themselves every week.

Each row links to a skill repository. Each skill belongs to its owner.
