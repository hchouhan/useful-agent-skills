# Useful Agent Skills

This is a list of skills made by other people.

A skill is a set of instructions for an AI coding agent. Examples of agents are Claude Code, Codex and Cursor.

We do not copy skills here. Each line links to the original repository.

## How to use the list

1. Open [SKILLS.md](SKILLS.md).
2. Pick the group that matches your job.
3. Pick a skill in that group.
4. Click its link.
5. Follow the instructions in that repository.

## How to suggest a skill

Read [CONTRIBUTING.md](CONTRIBUTING.md). It explains how to add a skill with a pull request.
